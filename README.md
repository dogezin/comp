

Este projeto é a implementação de um compilador para uma linguagem de programação simples, focada em operações de calculadora. Ele foi desenvolvido como requisito para a disciplina de Compiladores e Interpretadores do Professor Valerio.

O compilador é capaz de analisar um arquivo de código-fonte, verificar a sintaxe, identificar erros semânticos (como o uso de variáveis não declaradas) e, se o código for válido, executar os cálculos respeitando a precedência de operadores.

**Autor:** Daniel Lodos da Ressurreição
**Usuário GitHub:** dogezin


   Node.js: Ambiente de execução para o JavaScript.
   ANTLR4: Ferramenta para geração do analisador léxico e sintático a partir de uma gramática.
   JavaScript (ES Modules): Linguagem de implementação do compilador.
